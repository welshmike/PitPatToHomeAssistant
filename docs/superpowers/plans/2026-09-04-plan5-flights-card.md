## Task 3: `FlightsService` on the network task + logo cache

**Files:** new `src/FlightsService.h/.cpp`, `src/NetTask.h/.cpp`, `src/NetManager.h` (expose `wifiUp()` — exists), `src/config.h.example`, `platformio.ini` (`board_build.filesystem = littlefs` for `[dial]`), `src/Guarded.h` (small mutex-guarded value template, or extend `SnapshotStore` into a template).

- [ ] Config: `HOME_LAT`, `HOME_LON` (doubles), `FLIGHTS_RADIUS_MI 3` in `config.h.example`; `#ifndef` fallbacks in `FlightsService.h` (`51.5074, -0.1278, 3`) so the build works without them, with a `#warning` on the Dial if `HOME_LAT` is not defined.
- [ ] `FlightsService` (device-only, runs on the net task): `begin()` (mount LittleFS on the `spiffs` partition with format-on-fail; `LittleFS.begin(true, "/lfs", 10, "spiffs")`), `setVisible(bool)` (atomic flag written from the loop task), `tick(nowMs)`: when visible and WiFi up and ≥ 20 s since last fetch → one adsb.fi GET (nm = miles × 0.868976), parse into a working snapshot, then for each aircraft (nearest first, budget: at most 3 enrichment requests per tick, remainder next tick) fill route → airports (two lookups, cached by ICAO in a 32-entry table), operator (cached by hex, 32 entries), airline IATA via `AirlineCodes` (or operator ICAO from hexdb when the callsign prefix fails); publish via `Guarded<FlightsSnapshot>`; `stale = true` when the adsb.fi fetch failed (keep the last list), `offline = !wifiUp`.
- [ ] HTTPS helper: `WiFiClientSecure` with `setInsecure()`, `HTTPClient` with 5 s connect/read timeouts, `Accept: application/json`, body read into a caller-provided buffer capped at 16 KB (`getStream()` loop), returns status and length. One request at a time; called only from the net task.
- [ ] Logo cache: `bool logo(const char* iata, const uint8_t*& data, size_t& len)`: if `/logos/{IATA}.png` exists in LittleFS, read into a service-owned 16 KB buffer (one logo resident at a time) and return it; else, when visible and not yet attempted this session, GET `https://pics.avs.io/120/48/{IATA}.png` (max 16 KB, only `image/png`), write to LittleFS, then return. Missing logo (404) is remembered per session so it is not retried. Expose `bool logoReady(iata)` for the UI to poll without triggering network work on the loop task — the download happens in `tick()` for the currently displayed airline (the UI tells the service which IATA it wants via `setWantedLogo(iata)`).
- [ ] Net task: bump stack to 12288; `NetTask::tick()` calls `flights.tick(millis())` after `net.tick()` and the publish drain. `NetTask` exposes `FlightsService& flights()`.
- [ ] Commit: `Add FlightsService: adsb.fi + hexdb enrichment on the net task, LittleFS logo cache`.
